# hassio-zigbee2mqtt-2

Home Assistant add-on repository providing a **second** Zigbee2MQTT instance
(`zigbee2mqtt_2`) for a second Zigbee coordinator.

It is the stock upstream stable add-on with a different slug — same official image,
same pinned version. See [`zigbee2mqtt_2/README.md`](zigbee2mqtt_2/README.md).

Add to Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories** →
`https://github.com/exytab/hassio-zigbee2mqtt-2`
